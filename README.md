# Pixabay Image Search Clone

## Description
A React.js web application that allows users to search, explore, and save high-quality images using the Pixabay API. The application is fully responsive and provides a smooth user experience across mobile, tablet, and desktop devices.

## Features
- Search images using keywords and categories.
- Browse trending and category-based images.
- Add and manage favorite images.
- Responsive masonry-style image grid layout.
- Lazy loading and pagination for better performance.

## Tech Stack
- Frontend: React.js, Tailwind CSS
- API: Pixabay API
- Tools: VS Code, Git & GitHub
